# Currency Rates

USD and EUR to hryvnia from the [NBU](https://bank.gov.ua/ua/open-data/api-dev), with 30-day charts.

## Install

Copy `wallpaper.lua` to the SD card as `/sd/wallpaper.lua`. Connect to Wi-Fi in Keira,
then open `/sd/wallpaper.lua` from the file manager once: the app downloads the data into `currency.txt`.
The wallpaper only reads that file (the launcher can't make network requests),
so open the app again from time to time to refresh it.

## Controls (app only)

- **A** — Refresh.
- **START** — Exit.
