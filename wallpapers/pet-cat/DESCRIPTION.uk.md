# Кіт-улюбленець

Кіт Мурчик живе на головному екрані. З плином справжнього часу він голоднішає й нудьгує,
а вночі (23:00–7:00) спить. Якщо нагодувати його чи погратися з ним уночі, він ненадовго прокинеться.

## Встановлення

Скопіюйте `wallpaper.lua` на SD-картку як `/sd/wallpaper.lua`. Щоб нагодувати, погратися
чи погладити кота, відкрийте `/sd/wallpaper.lua` з файлового менеджера. Його стан зберігається в `pet.txt`.

## Керування (лише в програмі)

- **A** — Нагодувати.
- **B** — Погратися.
- **C** — Погладити — кіт муркоче, трохи більше радості.
- **START** — Вихід.
