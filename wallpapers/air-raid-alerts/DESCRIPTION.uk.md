# Повітряні тривоги

Карта України з активними повітряними тривогами по областях з API
[ubilling.net.ua](https://ubilling.net.ua/aerialalerts/) (ключ не потрібен).
Області з тривогою пульсують червоним, а ті, де тривогу щойно скасували, кілька хвилин світяться зеленим.
Ваша область позначена кільцем.

## Встановлення

Скопіюйте `wallpaper.lua` на SD-картку як `/sd/wallpaper.lua` і підключіться до Wi-Fi у Keira.
Дані оновлюються кожні 30 секунд і в програмі, і на шпалерах (для шпалер потрібна свіжа Keira з мережевими модулями).
На старішій прошивці відкрийте `/sd/wallpaper.lua` з файлового менеджера, щоб оновити дані.
Останній стан зберігається в `alerts.txt`, а карта стає сірою, якщо даним понад 15 хвилин.

Вкажіть свою область у `HOME` на початку скрипта (за замовчуванням `м. Київ`) так, як вона називається в API,
наприклад `Львівська область`.

В API немає окремого запису для Криму, тому для нього показується статус Севастополя.

## Керування (лише в програмі)

- **A** — Оновити.
- **START** — Вихід.
