# Внески GitHub

Сітка ваших внесків на GitHub за останні 24 тижні з серією та найкращим днем.
Дані з [github-contributions-api](https://github.com/grubersjoe/github-contributions-api).

## Встановлення

Скопіюйте `wallpaper.lua` на SD-картку як `/sd/wallpaper.lua`. Підключіться до Wi-Fi у Keira
і один раз відкрийте `/sd/wallpaper.lua` з файлового менеджера: програма завантажить дані у `github.txt`.
Шпалери лише читають цей файл (лаунчер не може робити мережеві запити),
тож час від часу відкривайте програму знову, щоб оновити дані.

Вкажіть свій логін у `USER` на початку скрипта.

## Керування (лише в програмі)

- **A** — Оновити.
- **START** — Вихід.
