# Rain on the Window

Blurred night city lights behind the glass, drops sliding down and leaving trails, and lightning now and then.

## Install

Copy `wallpaper.lua` to the SD card as `/sd/wallpaper.lua`. The launcher shows it on the home screen.
The script also runs as an app: open it from Keira's file manager.

## Controls (app only)

- **START** — Exit.
