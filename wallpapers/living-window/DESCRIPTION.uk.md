# Живе вікно

Місто за вікном живе за справжнім київським часом: сонце й місяць (у реальній фазі)
пересуваються небом, а ввечері у вікнах загоряється світло.

## Встановлення

Скопіюйте `wallpaper.lua` на SD-картку як `/sd/wallpaper.lua`, і лаунчер покаже його на головному екрані.
Скрипт також працює як програма: відкрийте його з файлового менеджера Keira.

Використовує годинник, який Keira синхронізує через Wi-Fi; без нього доба минає за одну хвилину.

## Керування (лише в програмі)

- **A** — Прискорення часу.
- **START** — Вихід.
