# Living Window

A city outside the window, following the real Kyiv time: the sun and the moon (with its real phase)
move across the sky, and windows light up in the evening.

## Install

Copy `wallpaper.lua` to the SD card as `/sd/wallpaper.lua`. The launcher shows it on the home screen.
The script also runs as an app: open it from Keira's file manager.

Uses the clock Keira syncs over Wi-Fi; without it, a day passes in one minute.

## Controls (app only)

- **A** — Time-lapse.
- **START** — Exit.
