# Київське метро

Схема київського метро з потягами, що курсують усіма трьома лініями.
У години пік потяги ходять частіше, а вночі метро закрите.
Кожні кілька секунд підсвічується випадкова станція з її назвою.

## Встановлення

Скопіюйте `wallpaper.lua` на SD-картку як `/sd/wallpaper.lua`.
Години роботи задаються в `OPEN` і `CLOSE` на початку скрипта.

## Керування (лише в програмі)

- **Вліво / Вправо** — Попередня / наступна станція.
- **START** — Вихід.
