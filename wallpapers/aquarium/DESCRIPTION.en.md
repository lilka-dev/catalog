# Tropical Aquarium

Tropical fish swim at different depths among seaweed, coral and anemones.

## Install

Copy `wallpaper.lua` to the SD card as `/sd/wallpaper.lua`. The launcher shows it on the home screen.
The script also runs as an app: open it from Keira's file manager.

## Controls (app only)

- **A** — Bubbles.
- **B** — Show FPS.
- **START** — Exit.
