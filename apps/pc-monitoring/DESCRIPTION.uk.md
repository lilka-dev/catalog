# PC Monitoring

Дашборд для моніторингу ПК на Лілці. Опитує сервер Prometheus по WiFi та
відображає в реальному часі показники CPU, RAM, GPU, температур,
використання диска та будь-яких інших метрик, які збирає ваш Prometheus.

## Вимоги

- Картка microSD, відформатована в FAT32, з файлом `config.json` поруч із
  прошивкою (формат дивіться в папці
  [`sd_card_template/`](https://github.com/lilka-dev/PC_monitoring/tree/main/sd_card_template)
  репозиторію).
- Доступний сервер Prometheus (`prometheus.url` у `config.json`), який вже
  збирає потрібні метрики з відповідних експортерів.
- WiFi: або вже налаштований через KeiraOS (екран налаштування WiFi зберігає
  дані, які ця прошивка автоматично зчитує), або вказаний у `config.json`
  через `wifi.ssid` / `wifi.password` як резервний варіант.

## config.json

```json
{
  "wifi": { "ssid": "...", "password": "..." },
  "prometheus": { "url": "http://192.168.1.50:9090", "poll_interval_ms": 3000 },
  "clock": { "timezone_offset_min": 120, "ntp_server": "pool.ntp.org" },
  "queries": [
    { "label": "CPU", "query": "100 - (avg(rate(node_cpu_seconds_total{mode=\"idle\"}[1m])) * 100)" },
    { "label": "RAM", "query": "(1 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes)) * 100" },
    { "label": "GPU", "query": "avg(nvidia_smi_utilization_gpu_ratio) * 100" }
  ]
}
```

- `queries` необов'язковий: якщо пропустити, будуть використані вбудовані
  запити node_exporter за замовчуванням для CPU/RAM/GPU. Інакше можна
  вказати скільки завгодно показників `{"label", "query"}` — якщо вони не
  вміщаються на екран, вони гортаються сторінками через LEFT/RIGHT, а не
  відкидаються.

## Керування

- **A** — примусове оновлення (дашборд) / повернення до дашборда (екран статусу).
- **LEFT / RIGHT** — перемикання сторінки, коли показників більше, ніж вміщається на екрані.
- **START** — перемикання екрана статусу (стан WiFi/Prometheus, статус кожної метрики, остання помилка).

## Обробка помилок

- Якщо одна метрика не відповідає, лише її показник показує `N/A`/`ERR`, решта продовжують оновлюватись.
- Якщо всі запити провалились в одному циклі опитування, дашборд перемикається
  на повноекранний годинник із синхронізацією NTP та повідомленням
  "Prometheus unreachable, retrying...", і автоматично повертається назад,
  щойно опитування знову спрацює.
- Відключення WiFi обробляються автоматично з повторним підключенням кожні 30 секунд, без блокування інтерфейсу.
