# Twenty Forty Eight

Classic 2048 game (LUA engine).

## Description

Twenty Forty Eight is an implementation of the popular 2048 puzzle. Slide numbered tiles across a 4×4 board to merge matching values. The goal is to reach the **2048** tile, but the game doesn't end there 😉

- 4×4 board with colored tiles
- Each move adds a new tile (2 or 4) to a random empty cell
- Matching tiles merge, doubling their value
- High score is saved automatically
- Save and resume your game later

## Controls

| Button | Action |
|--------|-----|
| Arrow keys | Move tiles (left, right, up, down) |
| A | Start / Continue / New game |
| C | New game |
| D | Save game |
| Start | Exit |

## Installation

Copy the `twenty-forty-eight.lua` file to the device's SD card or install via the Lil Catalog directly in Lilka.
