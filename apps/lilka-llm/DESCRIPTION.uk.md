# Лілка LLM

!ДЛЯ РОБОТИ ПОТРІБНО ВСТАНОВИТИ З РЕПОЗИТОРІЯ(В РЕЛІЗАХ) МОДЕЛЬ І ПЕРЕМІСТИТИ В КОРІНЬ SD КАРТИ!
Україномовна локальна LLM модель яка запускається на лілці повністю, операє моделлю 15М параметрів або 30М, може розповісти історії, інформацію з документації або загальну інформації

## Можливості

- Писати промпти напряму з внутрішньої клавіатури без сторонніх інструментів.
- Писати промпти через ПК по WIFI або USB що би зручніше писати.
- Можливість запускати інші гіпотетичні моделі в майбутньому.
